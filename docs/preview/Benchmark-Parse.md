# 单模型解析 Benchmark

暖缓存，每种组合独立启动JVM，3次预热后10次采样；实际解析器及线程预算逐行列出。未启动Minecraft。
端到端加载包含I/O、纹理解码、宿主绑定、默认可见性与网格构建；native核心时间只覆盖核心parse调用，两项不能直接混比。动画脚本执行和GPU资源创建不在本表内。
CPU：AMD Ryzen 7 260 w/ Radeon 780M Graphics，8物理核/16逻辑处理器；自动预算按逻辑处理器数。
本批解析的同期进程快照未完整取得，可能影响结果；原始数据：build/preview/benchmark/parse-*.csv。
