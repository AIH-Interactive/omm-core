# 单模型解析 benchmark

日期：2026-11-07；Windows x64 Release，Java 25，JVM 堆上限 `-Xmx4g`。每个模型独立串行测试；同一 JVM 对比 Java 单线程与 native 1／8／16 线程。输入预先驻留内存，不包含磁盘读取。每条路径预热 5 次、测量 20 次，耗时单位 ms。

DLL SHA-256：`577fc8211abb41b77e92931b61bdcf930cd5dc942a32cd9c35f50e58b49087a1`。命令：`./tools/m2/Measure-Parser.ps1`。原始摘要：`build-m2-benchmark.log`。该数据测于最终 raw 骨骼环检测补充之前；上面的哈希标识实际受测 DLL，不作为后续产物的哈希。

`native` 包含 JNI parse/release；`native+jni` 另含 metadata/animations/controllers 传输；`native+jni+bind` 再加入 Gson 解析的绑定代理，尚未覆盖游戏内正式绑定。Java 分配量仅统计调用线程；native retained 为额外非计时解析的保留容量，均不是峰值 RSS。Java 的 retained 为不适用。

**环境负载：可能影响结果。** 基准末尾的进程快照发现 10 个启用 nodeReuse 的 MSBuild.exe 节点，可能含其他会话或空闲复用节点；仅凭进程存在不能判断实际编译负载。本会话未在计时期间并行编译或测试。未发现其他 Java／CTest 测试进程；该快照不覆盖整个测量期间。
